# Web Importer

เครื่องมือ local สำหรับดึงรายการ chapter จากหน้าสารบัญ ผ่าน FlareSolverr แล้วรวมตอนที่ดึงสำเร็จเป็นไฟล์ข้อความ UTF-8 ไฟล์เดียว หรือจัดรูปแบบและตัดช่วงจากไฟล์ `.txt` ที่มีอยู่แล้ว

## Requirements

- Node.js 20 หรือใหม่กว่า
- FlareSolverr ทำงานอยู่ที่ `http://127.0.0.1:8191`

## Run

### Docker local

ใช้ FlareSolverr ที่รันอยู่บนเครื่องที่พอร์ต `8191` (ดูคำสั่งด้านล่าง) แล้วรัน:

```powershell
Set-Location 'E:\web-importer'
docker compose up -d --build
```

เปิด [http://127.0.0.1:8787](http://127.0.0.1:8787) โดย container จะเชื่อม FlareSolverr ผ่าน `http://host.docker.internal:8191` และเปิดพอร์ตเว็บเฉพาะ localhost

ดู log ด้วย `docker compose logs -f` และหยุดเว็บด้วย `docker compose down` เมื่อแก้ไฟล์โปรเจกต์ ให้รัน `docker compose up -d --build` อีกครั้ง

### Node.js

เปิด PowerShell แล้วรัน:

```powershell
Set-Location 'E:\web-importer'
npm install
npm start
```

จากนั้นเปิด [http://127.0.0.1:8787](http://127.0.0.1:8787)

## Start FlareSolverr

ถ้ายังไม่มี FlareSolverr ให้รัน Docker:

```powershell
docker run -d --name flaresolverr -p 8191:8191 ghcr.io/flaresolverr/flaresolverr:latest
```

ค่าเริ่มต้นใช้ `http://127.0.0.1:8191` หากใช้ endpoint อื่นในเครื่อง ให้ตั้งค่า `FLARESOLVERR_URL` ก่อน `npm start`:

```powershell
$env:FLARESOLVERR_URL = 'http://127.0.0.1:8191'
npm start
```

## Usage

หน้าเว็บมี 2 แท็บ: `ดึงจากเว็บ` และ `จัดการไฟล์ .txt` สลับแท็บระหว่างดึงได้ งานที่ดึงอยู่จะทำต่อ และแท็บ `ดึงจากเว็บ` แสดงความคืบหน้า เช่น `45/100`

### ดึง chapter จากเว็บ

1. วาง URL หน้าสารบัญนิยาย แล้วกด `ดึงสารบัญ`
2. เลือกตอน: ทุกตอนถูกเลือกไว้ก่อน ใช้ `เลือกทั้งหมด`/`ยกเลิกทั้งหมด`, พิมพ์ช่วงเลขตอนแล้วกด `เลือกช่วง` (เช่น 101–200), คลิกแถว หรือ Shift + คลิกเพื่อเลือกเป็นช่วง ปรับ `เริ่มเลขที่ #` หรือ `สลับลำดับ` ได้
3. ปรับ `หน่วง (ms)` และ `พร้อมกัน` ในแผงด้านขวา แล้วกด `เริ่มดึง N ตอน` ระบบดึงเฉพาะตอนที่เลือกและยังไม่เคยดึง สถานะแต่ละตอนแสดงในแถวของรายการ
4. หากต้องการหยุด กด `หยุด` ระบบจะหยุดคิวและคำขอจากหน้าเว็บ พร้อมเก็บตอนที่สำเร็จไว้
5. ถ้ามีตอนที่ล้มเหลวหรือถูกหยุด กด `ลองดึงตอนที่ไม่สำเร็จ (k)` เพื่อดึงเฉพาะตอนเหล่านั้นใหม่
6. กด `ดาวน์โหลด .txt (n ตอน)` เพื่อบันทึกตอนที่เลือกและดึงสำเร็จแล้วเป็นไฟล์เดียวตามลำดับในรายการ หรือกด `คัดลอกข้อความ (n ตอน)` เพื่อคัดลอกข้อความเดียวกันไปวางที่อื่นโดยไม่ต้องดาวน์โหลด กดได้ทั้งระหว่างดึงและหลังดึงเสร็จ
7. `เริ่มใหม่` ล้างรายการทั้งหมดแต่คง URL ไว้ ถ้ามีตอนที่ดึงสำเร็จ ระบบจะถามยืนยันก่อน (เช่นเดียวกับการดึงสารบัญใหม่)

ไฟล์ที่ export จากเว็บใช้ชื่อรูปแบบ `chapters-YYYYMMDD-HHmm.txt` และเข้ารหัส UTF-8 โดยไม่มี HTML หรือโฆษณาหลักจากหน้าเว็บ พร้อมลบชื่อตอนที่ซ้ำอยู่บรรทัดแรกของเนื้อหาออกให้แล้ว แม้ชื่อในสารบัญจะถูกตัดสั้น ขาดเครื่องหมายวรรคตอน หรือเลขตอนไม่ตรงกับหน้าเนื้อหา โดยใช้เลขตอนจากสารบัญคู่กับชื่อตอนที่ครบที่สุด

### จัดรูปแบบและตัดช่วงจากไฟล์ `.txt`

แท็บ `จัดการไฟล์ .txt` ทำงานในเบราว์เซอร์โดยตรง ไฟล์จะไม่ถูกอัปโหลดไปที่ server หรือ FlareSolverr

1. เลือกไฟล์ `.txt`
2. เลือก encoding เป็น `อัตโนมัติ` หรือระบุ `UTF-8`, `GB18030`, `GBK`, `Big5` ให้ตรงกับไฟล์
3. ตรวจหรือแก้ช่วงตอน ค่าเริ่มต้นคือ `205` ถึง `400`
4. กด `จัดรูปแบบและตัดช่วง`
5. ตรวจตัวอย่างผลลัพธ์ แล้วกด `ดาวน์โหลดผลลัพธ์` หรือ `คัดลอกผลลัพธ์` (คัดลอกผลลัพธ์ทั้งหมด ไม่ใช่เฉพาะส่วนที่แสดงตัวอย่าง)

ขั้นตอนนี้ทำเหมือนสคริปต์ `format_novel.py` และ `extract_range.py`: รองรับ UTF-8, UTF-8 BOM, GB18030, GBK และ Big5, เติม `章` ให้หัวตอนที่ยังไม่มี, จัดบรรทัดว่างรอบหัวตอน และตัดช่วงแบบรวมตอนต้นและตอนท้าย ไฟล์ผลลัพธ์ใช้ชื่อเช่น `formatted-chapters-205-400.txt` และบันทึกเป็น UTF-8

## Development

ใช้คำสั่งนี้เพื่อให้ server restart เมื่อแก้ไฟล์:

```powershell
npm run dev
```

รัน test suite:

```powershell
npm test
```

การทดสอบ end-to-end ใช้ FlareSolverr test double ในเครื่อง จึงไม่ต้องเปิด FlareSolverr จริงสำหรับ automated tests

## Notes

- Server bind เฉพาะ `127.0.0.1` ไม่เปิดให้เครื่องอื่นใน network เข้าถึง
- รองรับ URL `http` และ `https` เท่านั้น
- การดึงเนื้อหาหลายตอนจะทำพร้อมกันตามค่า concurrency และเว้นระยะเริ่มแต่ละ request อย่างน้อยตามค่า delay เพื่อไม่ยิง request ต่อเนื่องเร็วเกินไป ค่า delay คงที่ตลอดการดึง จึงดึงหลายร้อยตอนได้ด้วยความเร็วเท่าเดิม
- ใช้เครื่องมือนี้กับเว็บไซต์และเนื้อหาที่คุณมีสิทธิ์เข้าถึงและดาวน์โหลด
